Сходимость по сетке (Richardson Extrapolation)

Метод проверяет порядок аппроксимации численной схемы без аналитического решения.

Интуиция

Пусть $u_h$ — численное решение на сетке с шагом $h$. При правильной реализации схемы второго порядка должно выполняться:

\[\| u_h - u_\text{exact} \| \approx C \cdot h^2\]

Мы не знаем $u_\text{exact}$, но можем оценить порядок схемы, сравнивая решения на трёх вложенных сетках: $h$, $h/2$, $h/4$ (т.е. при $N$, $2N$, $4N$).

Математическая идея

Обозначим ошибку: $E_h = u_\text{exact} - u_h \approx C h^p$.

Тогда:

\[u_h - u_{h/2} = (u_\text{exact} - u_{h/2}) - (u_\text{exact} - u_h) = E_{h/2} - E_h \approx C h^p\left(\frac{1}{2^p} - 1\right)\]

Аналогично:

\[u_{h/2} - u_{h/4} \approx C h^p\left(\frac{1}{4^p} - \frac{1}{2^p}\right)\]

Отсюда:

\[\frac{\| u_h - u_{h/2} \|}{\| u_{h/2} - u_{h/4} \|} \approx 2^p\]

Для схемы второго порядка ($p = 2$) это отношение должно быть ≈ 4.

Таблица ожидаемых результатов

Порядок схемы $p$Ожидаемое отношение
1≈ 2
2≈ 4
4≈ 16

Алгоритм проверки

  1. Решить прямую задачу при $N$, $2N$, $4N$ (с пропорциональным $M$).
  2. Интерполировать решения на общую мелкую сетку.
  3. Вычислить нормы разностей: $d_1 = \|u_N - u_{2N}\|$, $d_2 = \|u_{2N} - u_{4N}\|$.
  4. Проверить: $d_1 / d_2 \approx 4$.

Что значит «тест упал»

  • Отношение ≈ 1: схема не сходится или сетка слишком мелкая и доминирует ошибка округления.
  • Отношение ≈ 2: схема первого порядка — возможна ошибка в аппроксимации граничных условий.
  • Отношение >> 4: возможно влияние переходного слоя (сгущение на сетке Шишкина компенсирует ошибку нерегулярной части решения).

Особенности для сингулярно возмущённых задач

При малом $\varepsilon$ решение содержит тонкий переходный слой шириной $\sim \varepsilon$. На равномерной сетке аппроксимация вблизи слоя может быть первого порядка, а сетка Шишкина восстанавливает второй порядок. Тест на сходимость позволяет убедиться, что выбранные параметры сетки Шишкина подобраны правильно.

В данном пакете

Тест реализован в test/convergence.jl. Для интерполяции между сетками используется Dierckx.Spline1D. Нормы берутся в $L_\infty$ (максимум по всем узлам).
