# Проверка градиента: конечные разности и тест Тейлора

Два взаимосвязанных метода, которые проверяют корректность вычисления
градиента функционала ``J(q)`` через сопряжённую задачу.

## Почему это важно

Функционал ``J(q) = \int_0^T (u(f_1(t), t; q) - f_2(t))^2\,dt`` зависит
от ``q`` неявно — через решение прямой задачи ``u``. Формула для градиента
```math
\nabla_q J = -\int_0^T u(x, t; q)\,\psi(x, t; q)\,dt
```
выводится через сопряжённую задачу. Ошибка в выводе или реализации приводит к тому,
что минимизация идёт не туда: функционал не убывает или убывает медленно.

Эти методы позволяют поймать такие ошибки без аналитического решения.

---

## 1. Градиентный чек (конечные разности)

### Математическая идея

По определению производной:
```math
\frac{\partial J}{\partial q_i} \approx
\frac{J(q + \varepsilon\,e_i) - J(q - \varepsilon\,e_i)}{2\varepsilon}
```
где ``e_i`` — единичный вектор по направлению ``i``.

Правая часть вычисляется двумя прогонами прямой задачи с возмущённым ``q``.
Левая часть вычисляется через сопряжённую задачу.
Они должны совпадать.

### Алгоритм

1. Зафиксировать точку ``q_0`` (например, нулевое начальное приближение).
2. Решить прямую задачу → ``u``, сопряжённую → ``\psi``.
3. Вычислить ``\nabla J = J\_q(u, \psi, \ldots)``.
4. Для нескольких индексов ``i``:
   - Решить прямую задачу с ``q_0 + \varepsilon e_i`` → ``J_+``
   - Решить прямую задачу с ``q_0 - \varepsilon e_i`` → ``J_-``
   - Конечно-разностная производная: ``(J_+ - J_-) / (2\varepsilon)``
5. Сравнить с соответствующей компонентой ``\nabla J``.

### Выбор шага ``\varepsilon``

| ``\varepsilon`` | Ошибка усечения | Ошибка округления |
|:---:|:---:|:---:|
| ``10^{-3}`` | ``O(h^2) \sim 10^{-6}`` | пренебрежима |
| ``10^{-5}`` | ``O(h^2) \sim 10^{-10}`` | начинает проявляться |
| ``10^{-8}`` | пренебрежима | ``O(\varepsilon_\text{machine}) \sim 10^{-8}`` |

Оптимальный выбор: ``\varepsilon \approx 10^{-5}`` для задач в формате `Float64`.

### Что значит «тест прошёл»

Относительная погрешность ``|\nabla J_i - \text{FD}_i| / |\text{FD}_i| < 5\%`` для
нескольких компонент, включая границы и центр области.

### Ограничения

- При ``q_0 = q_\text{true}`` функционал близок к нулю и ``\nabla J \approx 0``.
  Относительная погрешность в этом случае плохо определена — лучше проверять
  при ``q_0 \neq q_\text{true}``.
- Тест проверяет корректность в конкретной точке ``q_0``, а не глобально.

## 2. Тест Тейлора

### Математическая идея

Если ``\nabla J`` — правильный градиент, то по разложению Тейлора:
```math
J(q + \alpha\,\delta q) - J(q) = \alpha\,\langle \nabla J,\, \delta q \rangle + O(\alpha^2)
```

Определим:
```math
\Psi_1(\alpha) = \frac{J(q + \alpha\,\delta q) - J(q)}{\alpha}
```

При правильном градиенте ``\Psi_1(\alpha) \to \langle \nabla J, \delta q \rangle`` при ``\alpha \to 0``,
причём скорость сходимости — **первый порядок по ``\alpha``**.

### Таблица ожидаемых результатов

При правильном градиенте:

| ``\alpha`` | ``\Psi_1(\alpha)`` | Относ. погрешность |
|:---:|:---:|:---:|
| ``0.1`` | близко к ``\langle \nabla J, \delta q\rangle`` | ``\sim 10\%`` |
| ``0.01`` | ближе | ``\sim 1\%`` |
| ``0.001`` | ещё ближе | ``\sim 0.1\%`` |

Каждый раз при уменьшении ``\alpha`` в 10 раз ошибка тоже уменьшается примерно в 10 раз.

### Что значит «тест упал»

Если ``\Psi_1(\alpha)`` не сходится к ``\langle \nabla J, \delta q \rangle``
или сходится медленнее первого порядка — градиент вычислен неправильно.

Типичные причины:
- Неправильный знак в сопряжённом уравнении.
- Ошибка в вычислении члена неоднородности.
- Неправильный порядок разворачивания времени при передаче ``\psi`` в ``J\_q``.

### В данном пакете

Тест реализован в `test/gradient_check.jl`.
Ключевой момент: `solve_adjoint` возвращает ``\psi`` в **обратном** порядке по времени
(от ``T`` до ``0``), а `J_q` ожидает **прямой** (от ``0`` до ``T``).
Поэтому при вызове передаётся `ψ[:, end:-1:1]`.
