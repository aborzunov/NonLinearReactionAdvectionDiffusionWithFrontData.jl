# Тест скалярного произведения (Dot Product Test)

Структурная проверка согласованности прямого и сопряжённого операторов.
Не требует ни аналитического решения, ни полного прогона задачи.

## Интуиция

В линейной алгебре транспонированная матрица ``A^\top`` определяется через свойство:
```math
\langle A\,u,\, v \rangle = \langle u,\, A^\top v \rangle \quad \forall\, u, v
```

Если есть линейный дифференциальный оператор ``L``, то его **сопряжённый** оператор ``L^*``
определяется аналогично через скалярное произведение в функциональном пространстве:
```math
\langle L\,u,\, \psi \rangle = \langle u,\, L^*\psi \rangle
```

В задаче идентификации коэффициента **прямой оператор** — линеаризованный Якобиан
``\partial \text{RHS}_\text{direct} / \partial y``, а **сопряжённый** — матрица системы
сопряжённой задачи ``\partial \text{RHS}_\text{adjoint} / \partial \psi``.

Тест проверяет, что эти два оператора действительно согласованы.

## Математическая идея

Возьмём два произвольных вектора ``u, \psi \in \mathbb{R}^{N-1}`` и фиксированный шаг ``m``.

Вычислим:
- ``L[u] = \text{DRP\_y}(u, m, \ldots)`` — Якобиан правой части прямой задачи.
- ``L^*[\psi] = \text{ARP\_y}(\psi, m, \ldots)`` — Якобиан правой части сопряжённой задачи.

Если операторы согласованы:
```math
\langle L[u],\, \psi \rangle = \langle u,\, (L^*)^\top \psi \rangle
```

!!! note
    Здесь ``L^*`` — это уже дискретный сопряжённый оператор (матрица).
    Если его транспонировать, получим ``L^\top``. Тест проверяет, что
    ``L^\top \approx L^*``, т.е. что дискретный сопряжённый оператор
    совпадает с транспонированием дискретного прямого оператора.

## Откуда берётся расхождение в нелинейном случае

Прямое уравнение нелинейно: ``\partial u / \partial t = F(u, q)``.
Линеаризация вокруг текущего ``u^s``:
```math
\frac{\partial \delta u}{\partial t} = \frac{\partial F}{\partial u}\bigg|_{u^s} \delta u
```
Сопряжённое уравнение выводится из условия совпадения скалярных произведений
с точностью до нелинейных членов. При неоднородном ``q`` и нелинейном члене адвекции
``u \partial u / \partial x`` точное равенство достигается лишь для **линейных** операторов.

На дискретном уровне для нашей схемы:
- ``(L)_{ij}`` — элементы Якобиана `DRP_y` (прямая задача),
- ``(L^*)_{ij}`` — элементы Якобиана `ARP_y` (сопряжённая задача).

Линейная часть (диффузия ``\varepsilon \partial^2 / \partial x^2``) должна быть симметрична.
Нелинейная часть (адвекция ``u \partial u / \partial x``) даёт несимметричный вклад,
поэтому полное совпадение ``L^\top = L^*`` достигается только приближённо.

## В данном пакете

Тест реализован в `test/adjoint_consistency.jl`.
Проверяется на фиксированном шаге ``m = 1`` с произвольными векторами ``u, \psi``.
Допустимое отклонение определяется порядком аппроксимации.
