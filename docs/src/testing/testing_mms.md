# Метод добавленного источника (MMS)

Метод добавленного источника (Manufactured Solution, или MMS) позволяет
проверить корректность численной схемы даже тогда, когда аналитическое
решение исходного уравнения неизвестно.

## Интуиция

Представим, что мы не можем найти точное решение уравнения
```math
\frac{\partial u}{\partial t} = \varepsilon\frac{\partial^2 u}{\partial x^2}
+ u \frac{\partial u}{\partial x} - q(x)\,u
```
Но мы хотим убедиться, что наша схема работает правильно.

**Ключевое наблюдение:** мы свободны выбирать любую функцию ``u^*(x,t)``
и сделать её точным решением, если добавим нужный источник.

## Математическая идея

1. Выбираем произвольную гладкую функцию ``u^*(x,t)``, например ``u^*(x,t) = (1-2t)\sin(\pi x)``.

2. Подставляем её в уравнение. Результат не равен нулю — это и есть «невязка»:
```math
r(x,t) = \frac{\partial u^*}{\partial t} - \varepsilon\frac{\partial^2 u^*}{\partial x^2}
- u^* \frac{\partial u^*}{\partial x} + q(x)\,u^*
```

3. Модифицируем правую часть уравнения, вычтя невязку:
```math
\frac{\partial u}{\partial t} = \varepsilon\frac{\partial^2 u}{\partial x^2}
+ u \frac{\partial u}{\partial x} - q(x)\,u - r(x,t)
```

4. По построению, ``u^*`` является **точным** решением этого нового уравнения.

5. Решаем модифицированное уравнение нашей схемой и сравниваем с ``u^*``.

## Что это проверяет и что не проверяет

**Проверяет:**
- Правильность аппроксимации дифференциальных операторов (диффузии, адвекции).
- Корректность граничных и начальных условий.
- Отсутствие ошибок в индексации и знаках.

**Не проверяет:**
- Корректность самой постановки задачи (можно проверить неправильное уравнение идеально).
- Качество аппроксимации при ``\varepsilon \to 0`` (пробная функция должна отражать физику задачи).

## Ограничения

- Пробная функция ``u^*(x,t)`` должна удовлетворять граничным условиям задачи.
- Чем «ближе» пробная функция к реальному решению по характеру (наличие переходного слоя,
  порядок гладкости), тем более информативен тест.
- Тест обнаруживает ошибки в аппроксимации, но не в постановке задачи.

## В данном пакете

Метод применяется в тестах `test/direct_check.jl` и `test/adjoint_check.jl`.
Пробная функция:
```math
g(x,t) = (1 - 2t)\sin(\pi x)
```
удовлетворяет нулевым граничным условиям ``g(0,t) = g(1,t) = 0`` при всех ``t``.

Схема Розенброка модифицируется передачей функции `RP` с добавленным источником,
якобиан при этом остаётся прежним (источник не зависит от ``u``).
